# SESH Office

A modern office productivity SaaS interface inspired by Microsoft 365, built with Next.js and Tailwind CSS.

## Features
- Landing page and polished marketing UI
- Authentication screen
- Workspace dashboard
- Documents workspace
- Sheets workspace
- Slides workspace
- Settings and team management views
- Responsive dark/light SaaS design

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Production build

```bash
npm run build
npm run start
```
